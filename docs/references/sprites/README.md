# Referências visuais do Projeto R

Imagens conceituais fornecidas para o Projeto R. Elas ficam em `docs/` para não serem importadas pelo Unity.

## Organização

- `player/`: cinco referências do protagonista (`player-01.png` a `player-05.png`).
- `npcs-vila/`: 21 referências de personagens/NPCs (`npc-vila-01.png` a `npc-vila-21.png`).
- `castelo-morigan/`: cinco referências do Castelo Morigan (`castelo-morigan-01.png` a `castelo-morigan-05.png`).

Os nomes foram simplificados para navegação. A ordem original foi preservada e os PNGs foram movidos sem recompressão ou alteração de pixels.
