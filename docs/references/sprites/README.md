# Referências visuais do Projeto R

As imagens desta pasta são as versões finais fornecidas nas pastas de referência do Projeto R em 03/10/2026.

## Organização

- `player/`: cinco referências do player/protagonista.
- `npcs-vila/`: 21 referências de personagens/NPCs da vila.
- `castelo-morigan/`: cinco referências da área de mundo/família e personagens do Castelo Morigan, recebidas na pasta de origem `Mundo`.

Os nomes preservam a ordem e o horário de geração presentes nos arquivos de origem. Como os arquivos não traziam nomes de personagens, os rótulos usam a função e o local sem atribuir identidades não confirmadas. Os PNGs foram copiados sem recompressão ou alteração de pixels.
